# SuperorganismToxicity_Thesis_RaquelGarciaPerez
Data and code supporting the MSc thesis on colony-level responses to chronic cadmium exposure in Bombus terrestris. Conducted by Raquel Garcia Perez as part of the MSc in Ecology, Evolution, and Conservation at Imperial College London.

The files contained in this repository and their relevance in this thesis are described below:

### thesis_analysis.R – R script containing all code used for data analysis throughout the project.

### temperature_humidity.csv – CSV file containing all temperature measurements recorded by the hive sensors during experimental phase.
### pollen_consumption.csv – CSV file containing all pollen consumption measurements recorded during experimental phase.
### results.csv – Results from all blob detector parameter combinations, provided due to the time and computational power required to test them all.

### Automatic_blob_measurement.ijm – Fiji macro developed to extract area measurements from blobs detected using the DoH algorithm.

### 17-06-26 folder – Folder containing recordings (.MOV files) from three different colonies (C6,C14,C1) collected on this date.
### 19-06-26 folder – Folder containing recordings (.MOV files) from three different colonies (C6,C14,C1) collected on this date.
### Annotated_Images – Folder containing six CLAHE-processed images from three colonies (C6, C14, and C1) across two sampling dates (17/06/26 and 19/06/26).
### Manual annotations – Folder containing Fiji measurements of manually annotated cocoons and honey pots from the six selected CLAHE images. Files are named according to object type (cocoon/honey pot), colony ID, and sampling date (e.g., HC_Cocoons_C6_170626).


### MonitorRaiser_LegsBase_3DPiece.stl – Design of the supporting base of the monitor riser during colony recordings. Created in Tinkercad.
### MonitorRaiser_HeightExtension_3DPiece.stl – Design of the intermediate 3D pieces used to extend the height of the monitor riser during colony recordings. Created in Tinkercad.
### MonitorRaiser_MonitorFittingComponent_3DPiece.stl – Design of the fitting piece used to connect the intermediate 3D height extension pieces to the monitor riser during colony recordings. Created in Tinkercad.
